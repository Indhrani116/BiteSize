# BiteSize

AI-Powered Contextual Micro-Blogging Platform for Learners

## Overview

BiteSize is a MERN Stack web application that enables students to share educational snippets limited to 280 characters. The platform also integrates Google Gemini AI to provide Explain Like I'm 5 (ELI5) explanations for complex concepts.

## Features

- User Authentication (JWT)
- Create Educational Snippets
- Topic-based Search
- Like Posts
- Bookmark Posts
- User Profile
- AI-powered ELI5 Explanations
- Responsive UI

## Tech Stack

### Frontend

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
